# ekactl-typst

This requires the "Ethan standard style" to be installed to `@local/ethan-standard-style` on your machine.

You can do this by:
```bash
mkdir -p ~/.local/share/typst/packages/local/ethan-standard-style
cd ~/.local/share/typst/packages/local/ethan-standard-style
git clone https://github.com/ethanc8/ethan-standard-style-typst 0.1.0
cp local-conf-template.typ local-conf.typ
```
